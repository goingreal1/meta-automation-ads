# Landing page photos: ChatGPT image prompts

Generate each image in ChatGPT, save it with the **exact file name** into `images/landing/` and commit it.
Any file you don't add is simply not shown, so you can add them one at a time.

**Tips for all of them**
- Ask for **landscape** (1536×1024). The page crops to the right shape automatically, so keep the subject near the middle.
- Convert to **JPG, under 300 KB** (squoosh.app) so the page stays fast.
- If ChatGPT puts text, logos or fake UI words on a screen, add: "Screens show abstract charts only, no readable text, no logos."
- If a result looks too "stock", add: "candid, documentary photography, slightly imperfect, natural skin and fabric".

**Shared style line** (paste at the end of every prompt):
> Photorealistic editorial photography, natural daylight, shallow depth of field, calm confident mood, modern Lagos office, soft blue accents (#1877F2) in the scene, no text, no logos, no watermark, 3:2 landscape.
